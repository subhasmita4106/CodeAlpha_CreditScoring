# 💳 Credit Scoring Model

A machine learning project to predict an individual's creditworthiness using past financial data.

## 🔍 Overview
Built as part of the **CodeAlpha Machine Learning Internship**, this project applies classification algorithms to assess credit risk using the German Credit Dataset.

## 🛠️ Technologies Used
- Python
- Pandas, NumPy
- Scikit-learn
- Matplotlib, Seaborn

## 🤖 Models Used
- Logistic Regression
- Decision Tree
- Random Forest

## 📊 Evaluation Metrics
- Precision, Recall, F1-Score
- ROC-AUC Score
- Confusion Matrix

## 📁 Dataset
German Credit Dataset — UCI Machine Learning Repository
